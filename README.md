# Telegram Face Swap Bot — Render

## مهم قبل النشر

Render Free حاليًا محدود بـ 512MB RAM و0.1 CPU. هذه النسخة مصممة لتقليل الاستهلاك، لكنها ليست مناسبة لمعالجة فيديوهات طويلة أو 1080p على الخطة المجانية.

الخطة المجانية تستخدم نظام ملفات مؤقتًا، لذلك نماذج InsightFace قد تُعاد تهيئتها بعد restart/spin-down.

## التشغيل

1. أنشئ Bot من BotFather وخذ `BOT_TOKEN`.
2. ارفع هذا المجلد إلى GitHub.
3. في Render اختر `New -> Blueprint` واربط المستودع.
4. ضع:
   - `BOT_TOKEN` = توكن البوت
   - `PUBLIC_URL` = رابط Render، مثل `https://your-service.onrender.com`
5. Deploy.
6. افتح البوت واضغط `/start`.

## طريقة الاستخدام

- أرسل صورة الوجه المصدر.
- ثم أرسل الصورة الهدف.
- للفيديو: أرسل صورة المصدر ثم فيديو قصير.

## ملاحظات

- الحد الافتراضي للفيديو 20 ثانية و12MB.
- الدقة تُخفض إلى نحو 720p لتقليل RAM/CPU.
- أكبر وجه مكتشف في المصدر والهدف يُستخدم.
- هذه النسخة CPU فقط.
- استخدم فقط صورًا وفيديوهات تملك حق استخدامها أو لديك إذن لتعديلها.

## لماذا قد تفشل الخطة المجانية؟

نموذج تبديل الوجه + نماذج التعرف على الوجه + OpenCV + FFmpeg قد تتجاوز 512MB في بعض البيئات. عند حدوث `Out of Memory` لن يكون هناك حل برمجي سحري على نفس المواصفات؛ ستحتاج خدمة بذاكرة أكبر.
